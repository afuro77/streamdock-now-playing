# Security

This experimental source preview has no supported production release or security
SLA. Do not expose its loopback receiver to other computers or the Internet.
Only configure trusted launch targets; launch actions execute user-selected files
or URIs. Only install a reviewed extension build from a trusted local directory.

Never post OAuth tokens, DPAPI files, pairing URLs, runtime config or full logs in
an issue. If GitHub private vulnerability reporting is available, use it. Otherwise
open a minimal issue requesting a private reporting channel without exploit
details or credentials. Revoke leaked Spotify authorization immediately and
rotate the local browser pairing capability. Deleting a file from the latest
commit does not remove it from Git history.
