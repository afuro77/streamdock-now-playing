# Hardware demo recording plan

No hardware photo/video has been cleared for this repository yet. The overview
SVG is an original illustration and must not be described as a hardware recording.

## Thirty-second recording

| Time | Show | Caption |
|---|---|---|
| 0–5 s | Device on the desk with local Now Playing | Control music without switching screens |
| 5–10 s | Large-knob Play/Pause, left-knob track change | Artwork and metadata update |
| 10–15 s | Artwork expansion, then return | Press to expand |
| 15–21 s | Desktop mode: clock and configured app actions | Your own widgets and launch targets |
| 21–27 s | Optional YouTube speed adjustment, if permitted | Press, rotate, then return to seek |
| 27–30 s | Device and repository title | AKP03J owners: first-install testers welcome |

Record with a camera so the physical device and hand movements are visible.
Use your own permitted test audio/video/artwork, no personal notifications,
account names, pairing URLs or credentials. Do not use commercially released
album artwork or YouTube video frames as promotional assets without permission.
If the optional browser demo is omitted, use that time for app-launcher setup.

Take one clear desk photo and one close-up of the six LCDs with original sample
media. Review every frame before committing. Prefer a linked permitted video;
keep large media out of Git history. Add reviewed assets explicitly, without
removing the broad private-media exclusions from .gitignore.

Publish the actual recording link near the top of both READMEs only when it exists.
