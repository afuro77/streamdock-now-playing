# AKP03J 操作マップ — DEV v1.2

## 下3物理ボタン：画面移動専用

| 左 | 中央 | 右 |
|---|---|---|
| HOME | BROWSE | BACK |
| いつでも通常画面 | Queueを開く | 画面へ／元の曲へ |

押した瞬間だけ、右下LCDに名前を約1秒表示します。常設の案内はありません。
BROWSE内のBACKは前の画面へ。通常画面のBACKは直前のQueue選曲で進んだ分だけ元の曲へ戻します。

## 通常画面（6 LCD）

| 左 | 中央 | 右 |
|---|---|---|
| ジャケット左上 | ジャケット右上 | 曲名・アーティスト |
| ジャケット左下 | ジャケット右下 | PLAY/PAUSE・経過時間・進捗 |

- 左4枚のどれかを押す：全面ジャケット。
- 右上を押す：全面曲情報。長文は横スクロール。
- 右下を押す：再生／一時停止。
- 全面表示中はLCDのどれかを押すと通常画面へ戻ります。
- 全面表示は無操作30秒で通常画面へ戻ります。

## ノブ（全画面共通）

| ノブ | 回す | 押す |
|---|---|---|
| 大ノブ | 音量 ±2／1目盛り | 再生／一時停止 |
| 左小ノブ | 前曲／次曲 | 未割当 |
| 右小ノブ | シーク ±5秒／1目盛り | Shuffle切替 |

Spotifyの音量は再生先を自動判定します。PC再生はSpotify.exeの音量、
Google Home等は対応する外部デバイスの音量を調整します。
外部再生先を操作できない場合にPC側音量へ勝手に切り替えることはありません。

## Queue画面

列ごとに、上段＝曲名・アーティスト、下段＝ジャケット。次の最大3曲です。
左列を押すと次へ1回、中央列は2回、右列は3回。上下どちらも同じ曲を選びます。
移動後は自動で通常画面へ戻ります。連打中の二重実行は防止します。
HOME／BACKは未送信の曲送りを止めて画面移動します。

## 画面移動の例

- 通常 → BROWSE → Queue → BACK → 通常
- 曲情報全面 → BROWSE → Queue → BACK → 曲情報全面
- どこからでも HOME → 通常
- Queue選曲後は通常へ。BACKで元の曲の曲頭へ戻します。
